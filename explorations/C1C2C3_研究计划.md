## 1. C1 —— C 的最小化（给定 n,m）

### 1.1 本轮证据

1. **argmin 度序列 92/92 全部拟正则**（全部 (n,m) 连通类，n≤9；max−min ≤ 1；8/92 带叶 = m<n 时拟正则度含 1，如树的 argmin = 路径）。
2. **安置效应显著但结构精确**：同度序列 ≥2 个连通实现的 3,375 类中 96% 有正 C-差（max 3.54）；**拟正则类内的差恰为 φ\*(r)·Δt**（φ\*(r) := margin(r,r+1) = φ(r,r+1) − h(r) − h(r+1)：φ\*(1)=0.2295, φ\*(2)=0.1310, φ\*(3)=0.0831；数据中 0.262 = 2φ\*(2)、0.1661 = 2φ\*(3) 精确吻合）——即 **C 对混边数 t 线性**。
3. **关键不等式 (a)**：$\varphi(a,b)\ge h(a)+h(b)$，$h(d)=(d-1)\,c(d,d)$——400×400 网格 **0 违反**；等号 ⟺ a=b；margin(a,·) 在 b≥a 上**单调递增**（120×300 网格 0 违反）、对称、margin(a,a+1) = Θ(1/a)。
4. **G(d) := d·h(d) = d(d−1)c(d,d) 整数点严格凸**：二阶差分最小 1.4142140 > 0（d ≤ 62；渐近 G″→√2，与 G ≈ d²/√2 一致）。

### 1.2 猜想定理（闭式链）

对固定 $(n,m)$（连通），设 $2m = nr + k$，$0\le k<n$（拟正则度：$n-k$ 个 $r$、$k$ 个 $r{+}1$）：

$$\boxed{\ C(G)\ \ge\ \underbrace{(n-k)\,G(r) + k\,G(r+1)}_{\text{拟正则下界 } LB(n,m)}\ +\ t_{\min}(n,m)\cdot\varphi^*(r)\ }$$

其中 $t_{\min}$ = 该类中被迫的混边（r–(r+1) 边）最小数（由奇偶/可图性决定：多数类为 0 或 1；退化类如"$n-k=1$"可更大）。等号 ⟺ 度序列拟正则 + 同度相邻（纯安置）+ 混边恰 $t_{\min}$。

**证明链**（每步证据已备）：
$$C=\sum_{uv}\varphi(d_u,d_v)\ \overset{(a)}{\ge}\ \sum_{uv}[h(d_u)+h(d_v)]=\sum_u d_u h(d_u)=\sum_u G(d_u)\ \overset{\text{Karamata}}{\ge}\ LB(n,m),$$
第一段等号 ⟺ 每条边两端同度（"纯"图）；第二段等号 ⟺ 度序列拟正则（G 严格凸）。混边修正：$C = H(ds) + \sum_{\text{混边}} \mathrm{margin}$，margin 在相邻度对上最小（=φ\*）→ 修正项 $t\cdot\varphi^*(r)$。

**即时推论**（已可独立成文）：
- 树中 **路径最小、星最大**：$C(P_n) = LB + 2\varphi^*(1)$（两片强制 2 条混边——精确验证吻合），$C(K_{1,n-1}) = m(m-1)c(m,1)$（= StarMax，已 Lean 化）——最大最小恰好配对；
- 新度序列下界 $C \ge \sum_u d_u(d_u-1)c(d_u,d_u)$（等号 ⟺ 纯图），与既有 psiSum 下界互补（正则图上精确、星图上松；psiSum 反之）。

## 2. C2 —— 夹逼等号刻画与紧性

### 2.1 本轮证据

- $C/\psi Sum\in[1.123349,\ 1.412696]$（273k 连通图），均值 1.3794；$C/(\sqrt2\,\psi Sum)$ 最大 0.998927——与解析预测**逐位吻合**：星 $K_{1,8}$：$\frac{2m+1}{\sqrt{m^2+1}+\sqrt{(m-1)^2+1}}=1.1233$；$K_9$：$\sqrt2\,(1-\frac{1}{4r-2})=1.4127$。
- 下界最紧前 4 名全是星/近星；上界最紧前 4 名全是正则/近正则——**渐近取等族唯一确定**。
- 显式 (n,m) 上界 $(\sqrt2/3)(kz(n{-}1)+z(r))$：连通类比值全谱 **[0.061, 0.419]**——报告只记录了最紧处 0.419（C₃），本轮补全：**该上界从不接近紧**，最松在稀疏图（(9,12) 比值 0.061）；argmax 度序列呈"贪心度集中"模式（8,1⁸ / 8,5,2⁴,1³ / 8,8,3,3,2⁵——hub+副 hub 的蜘蛛形）。

### 2.2 工作包（全部 S 级）

1. **严格不等式定理 + Lean**：$m\ge1$ 时 $\psi Sum < C < \sqrt2\,\psi Sum$（等号永不成立）。证明 = `denom_bounds` 等号条件分析（$x^2+y^2\le(x+y)^2$ 等号 ⟺ xy=0，对 a,b≥1 不可能；$2(x^2+y^2)\ge(x+y)^2$ 等号需 a=b 与 a−1=b 同时成立，不可能）——**已 Lean 化引理的直接推论，半小时级**。
2. **渐近取等刻画**：星族 ratio $=1+\frac1m+O(m^{-2})$（下界方向）、r-正则族 $=\sqrt2\,(1-\frac{1}{4r-2}+O(r^{-2}))$（上界方向）；刻画定理：ratio→1 ⟺ 图族渐近星形（最大度占比→1），ratio→√2 ⟺ 渐近正则。难度 2。
3. **紧 (n,m) 上界**：候选 $\max_{ds\,(n,m)} \mathrm{degSeqBound}(ds)$（degSeqBound 已是 Lean 定义、已验证为上界、均值紧度 0.697）；由 Schur-凸性最大值在"贪心蜘蛛"度序列达到 → 闭式。用本轮 argmax 数据（92 类全表在 JSON）拟合猜想 + 证明。难度 2.5–3，这是 C2 的实质新定理。

**风险**：低（全部站在已 Lean 化的不等式上）；价值 3（把 §8.4 的"sharp"故事补完整：严格性 + 渐近族 + 速率 + 紧上界），作为论文 I 增强章节或短文。

## 3. C3 —— C 的单射性：问题已被探针重述

### 3.1 本轮发现（改变问题本身）

1. **平凡核方向**：$\varphi(1,1)=0$ ⟹ 增删 $K_2$ 分量不改变 C。733 个"原始碰撞类"**全部**由此解释（剥离 (1,1) 胞元后碰撞数 = **0**）——单射性必须在模匹配方向/无 $K_2$ 分量意义下陈述。
2. **范围内单射升级为证明级**：n≤9 全部 288,266 图，按 A3 正规形计算 C 的精确整数坐标：55,087 个不同值，模匹配后 **0 碰撞**；最小真实间距 **3.206×10⁻⁸ 精确复现**（与报告一致，独立方法确认）。
3. **φ-权关系格丰富**：D4（9 胞元，基 {1,√2,√5,√10,√13,√17}，rank 6）→ 关系维数 **3**；D8（35 胞元，rank 20）→ 维数 **15**。抽象关系大量存在 ⟹ 单射性只能来自**可实现性约束**。
4. **最小精确碰撞对（本轮构造，三重验证）**：最小整数关系 $12\varphi(1,2)+8\varphi(2,2)=2\varphi(1,3)+4\varphi(2,3)+3\varphi(3,3)$（L1=29；L1=26 的关系被奇偶约束排除）两侧均可实现：
   - $G_1 = 5P_4 \sqcup P_6$（26 顶点，20 边）：胞元 12×(1,2) + 8×(2,2)；
   - $G_2$（8 顶点，9 边，度序列 3,3,3,3,2,2,1,1；显式构造已验证胞元恰为 3×(3,3)+2×(1,3)+4×(2,3)）；
   - $C(G_1)=C(G_2)=20\sqrt2-4\sqrt5\approx19.3400$（浮点差 7×10⁻¹⁵；**精确坐标向量逐分量相等**）。
   ⟹ **"C 几乎单射"对无界 n 为假**；报告的经验陈述在 n≤9 范围内依然成立（且本轮升级为证明级），但一般情形必须修正。
5. **结构守恒律**：碰撞强制 $\Delta M_1 = 2\,\Delta m$（验证：两图 $M_1-2m$ 均 = 28）。原因：权向量 $w(x,y)=x+y-2$ 与关系格正交（在全部格基上验证 = 0；可证——w 属于 φ-坐标矩阵的行空间，即存在固定的 Q-线性泛函从 φ-坐标恢复 x+y−2）。

### 3.2 修正后的定理纲领

- **T1（代数，已就绪）**：$C(N_1)=C(N_2)\iff N_1-N_2\in\Lambda_\Delta$（φ-权整数关系格）；HNF 基 = 可机器检验的证书。
- **T2（结构约束）**：$\Lambda_\Delta\subseteq\{\,v:\textstyle\sum(x+y-2)v_{xy}=0\,\}$（守恒律）+ 度整合性/奇偶约束（$x\mid\sum_y N_{xy}$ 型）——排除大量格点（如 L1=26 关系）。
- **T3（判定定理，Δ≤4 = 化学图）**：碰撞完全刻画 = "$\Lambda_4$ 中两侧均可实现的格点"；最小对 = 上述 $(5P_4\sqcup P_6,\ G_2)$（猜想：L1-最小）；参数化碰撞族（路径束 vs 紧图）；**推论：单射性成立范围**（n≤9 已证；一般"n < n₀(Δ) ⟹ 单射"的阈值定理——最小碰撞需 n ≥ 26 提示 n₀ 可观）。
- **T4（Lean）**：T1/T2 = 有限整数线性代数（HNF 证书以矩阵乘法形式化）；碰撞对证书 = 两个具体图 + $20\sqrt2-4\sqrt5$ 的根式算术（A3Delta.lean 模板直接复用）。

### 3.3 难度重估说明

原评估"难度 5"混合了两件事：(i) 代数核心——被 A3 机器**完全解决**（关系格可算、守恒律可证）；(ii) "证明单射"——**方向本身错了**（无界 n 下单射为假）。修正后的 C3b 是"刻画碰撞"：有明确对象（Λ + 可实现性）、有最小样本、有范围内定理（n≤9），难度 3.5、价值反升（反例 + 刻画 比 单射猜想 更有内容）。C3c（一般 Δ 的碰撞密度、无碰撞范围计数的渐近）保持难度 5——格的维数增长（D8 已 15 维）使它成为真正的数的几何/丢番图问题，长线独立推进，不阻塞 C3a/b 成文。
