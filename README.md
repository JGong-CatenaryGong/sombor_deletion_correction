## The Sombor deletion correction term: extremal structure, exact coincidence classification, and the information content of edge decks, with applications to chemistry

This package contains the complete source code, formal proofs, and result data
accompanying Paper B. Every number in the paper can be verified from the files here.

- **Manuscript (PDF)**: [`manuscript.pdf`](manuscript.pdf)
- **Repository**: <https://github.com/JGong-CatenaryGong/sombor_deletion_correction>

## Contents

| Directory | Contents |
|---|---|
| `lean/` | Lean 4 + Mathlib formalisation (12 Lean sources under `lean/StarTheorem/`, 2384 lines; builds to 97 theorems, 0 sorry/admit) |
| `src/` | Python verification pipeline (~30 scripts; exhaustive enumeration + invariant computation + validation) |
| `results/` | 50 result files (JSON/CSV); includes `graphs.jsonl.gz` (all 288,266 graphs with n ≤ 9) |
| `explorations/` | Exploratory analysis scripts and results (A3 Δ-classification, C-collisions, n=10 chemical graphs, octane isomers) |
| `manuscript.pdf` | Compiled manuscript (PDF) |
| `verify.sh` | One-command verification script |
| `MANIFEST.sha256` | SHA-256 checksums of all files |

## Quick verification

```bash
bash verify.sh
```

This runs (in order):
1. SHA-256 integrity check of all files
2. Lean 4 build (`lake build`, ~5 min with internet for Mathlib)
3. 96 automated Python data checks
4. Spot-checks of headline numbers against the result files
5. Octane data consistency check

**Prerequisites**: Lean 4 (elan, v4.34.0) with internet access; Python 3.10+ with numpy, scipy, sympy, networkx.

## What is verified

### Lean 4 formalisation (97 theorems, no sorry)

| Claim | Lean theorem name |
|---|---|
| Deletion identity, arbitrary symmetric kernel | `deletion_identity` |
| Local per-edge formula | `Tf_delete_singleton` |
| Mathlib gap: degree updates under `deleteEdges` | `degree_deleteEdges_left/right/of_ne` |
| C = 0 iff matching | `C_eq_zero_iff` |
| Regular graph closed form | `C_of_regular` |
| Sharp sandwich Ψ ≤ C ≤ √2Ψ | `psiSum_le_C`, `C_le_sqrt2_psiSum` |
| Zagreb sandwich Z/(4Δ−1) ≤ C ≤ (√2/3)Z | `zagreb_sandwich` |
| Star maximisation C ≤ m(m−1)c(m,1) | `C_le_star` |
| Star equality characterisation | `C_eq_star_iff` |
| Edge-type deletion identity | `edgeType_deletion_identity` |
| Diagonal union theorem | `Delta_diagonal_union` |
| Telescoping identities | `telescoping_one`, `telescoping_two` |
| √20 and √52 family certificates | `Delta_sqrt20_*`, `Delta_sqrt52_*` |

**Not formalised** (stated as boundary in the paper): the D ≤ 8 classification
(computational), the recovery theorem (companion paper), the degree-sequence lemma.

## Reproducing the paper

```bash
# Full pipeline (from enumeration to report):
cd src && bash regenerate_all.sh

# Or step by step:
python3 src/validate.py                    # 96 checks (~40 s)
python3 src/build_dataset.py               # enumerate all graphs (~35 s)
python3 src/compute_decks.py               # edge decks (~80 s, 22 workers)
python3 src/sombor_analysis.py             # identity + Δ analysis (~4 min)
python3 src/star_theorem.py                # extremal verification (~60 s)
python3 src/corr_analysis.py               # C theory + certificates
python3 src/c_information.py               # information content + ML (~5 min)
python3 explorations/A3_classify_D8.py     # D=8 classification (~85 s)
python3 explorations/C_probe.py            # C-collision probes
python3 explorations/c_chemistry_real.py   # octane isomers
```

## Data sources

- **Graphs**: exhaustive enumeration of all simple graphs with n ≤ 9 (validated against OEIS)
- **Chemical graphs**: connected, Δ ≤ 4 (OEIS A121941); n = 10 set has 89,402 members
- **Octane isomers**: property data from the moleculardescriptors.eu QSPR benchmark
  (Needham, Wei & Seybold), cross-checked against NIST WebBook
